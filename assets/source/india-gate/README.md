# India Gate source model

- **Work:** India Gate
- **Creator:** sujankdh
- **Source:** https://www.thingiverse.com/thing:7027090
- **License:** Creative Commons Attribution-ShareAlike (CC BY-SA)
- **Downloaded:** 2026-07-14

`india-gate-sujankdh.obj` is the original downloadable OBJ. The game derivative
is generated by `scripts/voxelize-obj.mjs`, which centres the mesh, maps its Z
axis to game height, scales it to 46 blocks, samples surface details and fills
closed volumes into compact voxel spans.

The generated voxel dataset in
`src/content/cities/delhi/landmarks/data/indiaGateVoxels.generated.ts` remains
available under the source model's CC BY-SA terms. Changes made by the Dilli
Blocks project include voxelization, scaling, material remapping and integration
into the ceremonial plaza.
